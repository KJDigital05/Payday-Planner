# Payday Planner
Personal finance planning application for workers with irregular incomes.

## Features
- Payday Budgeting
- Automate Bill Allocation
- Debt Tracking
- Savings Goals
- Spending Limit Calculations
- Forecasting

## Tech Stack
- Python
- Streamlit
- SQLite (Planned)

## Why I Built This 
As a student who works part time as a delivery driver with irregular biweekly income, I wanted a budgeting system that could help me to automatically prioritise bills, debt repayments, savings goals and essential spending.
